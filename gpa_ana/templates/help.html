gpa-ana reads student transcript PDFs, works out each student's GPA over the courses in a category (STEM, MEDICAL, LAW, …), and ranks the students by it. Use the two tabs in order: Run to analyse transcripts and save the results, then View to look at them.

1. Run — load PDF transcripts and save results

  1. PDF input: upload one or more transcript PDFs, or type the path of a folder on this computer that holds them. If you do both, the uploads are used.
  2. Output path: the folder to save results in. It is created if it does not exist.
  3. Categories: tick every category to rank. Each one gets its own ranking from the same read of the PDFs.
  4. Options (usually left alone): Minimum category courses holds back students with fewer courses than this in a category; Workers is how many PDFs are read at once (blank = automatic); Force OCR reads every page as an image, for scanned transcripts.
  5. Click Run analysis. The status appears at the bottom of the page — a running timer, then a summary of what was ranked and where it was saved, or the error if something went wrong.

Each category saves rank_<category>_gpa.csv and .json in the output folder; the CSV opens in any spreadsheet.

2. View — see each category's results

  1. Results folder starts on the folder the last run saved to. Type another folder and click Load to open older results.
  2. Category: pick one to show its ranking. Only categories that have results in that folder are listed.
  3. Click any column name to sort by it; click again to reverse.
  4. Click a student's row to open their transcript details: the original PDF on the left, and every course read from it on the right. Courses in bold, marked ✓, count toward the category. Close it with ×, Esc, or a click outside.
  5. Students listed under Held back were not ranked; the reason is shown next to each name.
